# Capturas do produto

Depois de configurar Supabase local e executar o seed, capture as telas reais e adicione aqui:

- `dashboard-light.png`: visão geral desktop, tema claro.
- `dashboard-dark.png`: visão geral desktop, tema escuro.
- `inbox-review.png`: interpretação do exemplo RAG, antes de confirmar.
- `today-mobile.png`: plano diário em tela de celular.

Não use dados pessoais nas capturas. Os smoke tests geram capturas da entrada em `test-results/`; essa pasta é descartável e ignorada pelo Git.
